# Developer experience investigation log

## Scope and method

Pass 3 re-read `../codex-run2.log` and repeated the pass-2 reproductions on 2026-10-28, 08:05–08:08 UTC. All requests were read-only: Hideki GraphQL and RPC (`eth_chainId`, `eth_call`, `eth_estimateGas`, `eth_getBalance`, `eth_getBlockByNumber`), staging REST GETs, and documentation GETs. No transaction was broadcast; no private key was used. `from` in simulations was a plain address. SDK 0.32.1 source and ABIs were checked against live responses. Tools were Go 1.27.3, go-ethereum 1.14.13, curl 8.14.1, and Python 3.13.5.

## Reproduced findings

1. **Indexer mark freshness — Major.** At 08:05:44Z and 08:07:00Z, BTC/ETH/SOL GraphQL `markPrice` and `markPriceUpdatedAt` remained fixed; every pool `tryGetMarkPrice()` returned `ok=true` with a changing mark. BTC indexer age grew from 3241 to 3317 seconds, ETH 2786 to 2862, SOL 691 to 767. See [01](../feedback/01-stale-indexer-mark.md) for raw values, commands, and the cadence request.
2. **Developers overview navigation — Minor.** At 08:06:06Z, the live Developers overview listed Contracts, HTTP API, WebSocket API, and Libraries but omitted the Perps guide. The guide and `llms.txt` Perps entry returned HTTP 200. See [02](../feedback/02-developers-overview-omits-perps.md).
3. **REST network split — Normal.** At 08:06:06Z, staging `GET /v0/orderbooks?symbols=BTC:USDso` returned HTTP 400 `invalid_param` / `unknown market symbols`. `GET /v0/markets` returned only SOMI, WBTC, and WETH spot markets. The Hideki GraphQL indexer simultaneously served BTC perp. The general HTTP API docs identify Shannon 50312; the Perps guide does not make the split explicit. See [03](../feedback/03-rest-network-split.md).
4. **Voucher eligibility — Major.** Fixed block 35217141 at 08:08:00Z: distributor address resolved, campaign active, grant 1000 USDso, budget 219234 grants, and two zero-STT addresses each had zero active pools, zero main-funded principal, and `isClaimed=false`. These are all SDK 0.32.1 eligibility checks, so its logic yields `eligible: true`; both `claim()` simulations returned `{"code":3,"data":"0x3e31dcc2"}`. The selector is absent from the SDK error ABI and live Errors page. Its cause remains unknown. See [04](../feedback/04-voucher-eligibility-false-positive.md).
5. **Perp revert reference — Normal.** During the 08:05 UTC probe, an unfunded BTC perp `placeOrder` `eth_call` and `eth_estimateGas` both returned `0x08c379a0...`, decoding to `ERC20: insufficient allowance`. The linked live Errors page did not contain perp selectors `0x714b36d6` or `0x3a23d825`, though the Perps guide names them. Keccak-256 of `MaxPositionSizeExceeded()`, `InsufficientCollateral()`, and `ImmediateOrCancelNoFill()` confirmed `0x714b36d6`, `0x3a23d825`, and `0xd48c4403`; only the last appeared on the Errors page. See [05](../feedback/05-perp-revert-reference.md).
6. **Hideki gas onboarding — Normal.** The Perps guide gives the app's linked-bot gas transfer path. The general Quick Start's public STT faucet instructions are explicitly under Shannon 50312; `testnet.somnia.network` labeled its page `Testnet, Shannon` at 08:07:22Z. Hideki RPC `eth_chainId` was `0xc4cf` (50383). We did not attempt a faucet claim and do not assert no separate faucet exists. See [06](../feedback/06-hideki-gas-onboarding.md).

All six pass-2 items still reproduced today; none was dropped.

## Checks that found no issue

- **Market decimals and order grid:** GraphQL returned 21 PERP markets at 08:05:43Z. Their symbols and `baseDecimals` exactly matched the six groups in the Perps guide (6: ADA/HYPE/PUMP/XRP; 7: XLM; 8: BTC/DOGE/ZEC; 9: SOL/SUI/TAO; 18: 1000PEPE/AVAX/BNB/ETH/LINK/LIT/VVV/WLD/ZRO; 24: NEAR). Every quote had 18 decimals and token `0xed7993A74dAe1e6656B704A424DcD8711aAf4F72`. Each pool's `getOrderBookParameters()` matched the indexer `tickSize`, `minQuantity`, `lotSize` exactly; **0/21 mismatches**. This was a no-finding check, retained deliberately.
- **Contracts and SDK addresses:** `getSystemConfig()` returned the documented MarginBank `0x478769E1177C0773c43A593DCCc4Ad15F15F1394`, USDso collateral `0xed7993A74dAe1e6656B704A424DcD8711aAf4F72`, factory `0xE631fAEE547baeE07353E290f0562ea67d856560`, liquidation engine `0xA66d3C24Ad4a389d863846905D8173e1017e9F4D`, and insurance fund `0x50826894D47C6D4f3BeA38BFDC7Dc5c5be171b80`; max leverage 20 and `fullyWired=true`. `getCreditGranter()` matched the documented VoucherDistributor. The BTC pool's `getOperatorPermissionsRegistry()` matched the documented operator registry `0x6B2FbfeD328FF5F20C0BE7D3C3437613aFFE8D3a`. SDK `SOMNIA_HIDEKI_TESTNET_ADDRESSES.collateral` is `0x9E9492cC533E8696A3b6afC7df730800DF75148f`, a different SDK-wide asset; the Perps guide correctly directs readers to the bank's system config for perp collateral. No incorrect address was established.
- **Network naming and links:** Hideki RPC returned chain 50383, SDK `hidekiTestnet` defines 50383, and the documented Tokyo explorer URL returned HTTP 200. All five local/relative Perps-guide links tested at 08:07:22Z returned HTTP 200 after resolving against the guide URL. Fragment targets were not separately validated. The Tokyo/Hideki/DreamDEX region names were explained by the page, so no separate naming issue was filed.
- **Gas figures:** The unfunded simulated order reverted for zero allowance under both `eth_call` and `eth_estimateGas`. No successful 3.2M resting-order or 7.7M IOC estimate was obtained, so the documentation figures were not evaluated and no mismatch was reported.
- **SDK ABI and stop-order value:** SDK 0.32.1 has a payable spot `placeOrder` ABI and a nonpayable perp `placeOrder` ABI. The Perps guide discusses a separate `placeOrderFor` raw/operator path and a 0.15 STT stop-order attachment. We found no read-only on-chain proof of a contradiction and filed no issue.
- **Direct GraphQL query:** The old pass-1 report that selected nonexistent `Market.symbol` was not kept. A valid query using `baseSymbol`, `quoteSymbol`, and `poolAddress` works; that earlier error alone did not show a product defect. The navigation issue in [02](../feedback/02-developers-overview-omits-perps.md) has independent current evidence.
